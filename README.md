# trench_VBD_Model — conforming P2 Poisson/obstacle study

Two-dimensional vertical-trench SiC device model: conforming Si/SiO2 mesh,
six-node (P2) triangles, and a sharp-depletion obstacle enforced through
nonnegative Bernstein coefficients on the charged silicon.

## Layout

- `conforming_fem.py`, `conforming_fem2.py` — assembly / solver utilities
- `mesh_stage2a.py`, `mesh_stage2b.py` — geometry and graded mesh construction
- `front_analysis.py`, `bc_audit*.py` — front extraction and boundary-condition audits
- `p2/` — the active P2 workstream (mesh builds, QP solves, F7 gates, records)

## Solver pipeline

1. Build the conforming mesh (`p2/p2_mesh_*.py`), archive as `*_p2mesh.npz`.
2. Assemble the P2 operator and Bernstein constraint matrix, solve the QP with OSQP.
3. Save the primal/dual checkpoint **before** any polishing.
4. Polish the KKT system matrix-free with row-scaled MINRES plus one or more
   residual-correction rounds (no large direct factorization).
5. Apply the full-set F7 gate in unscaled coordinates: stationarity,
   feasibility, multiplier sign, complementarity, oxide residual, overshoot.
6. Only then compute Bernstein-subdivision area bounds and front cuts.
